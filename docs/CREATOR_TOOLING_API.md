# Creator Tooling Api

Creator tools expose metadata schemas and validators. All new validators support text output and `--json`.

## 1.5.3 Defaults

- ECHO is the ecosystem.
- ECHO Launcher is the platform.
- Ashfall is Official ECHO Pack #1, not a requirement for reusable modules.
- Creator tooling uses schemas, examples, generators, validators, and docs rather than fake UI editors.
