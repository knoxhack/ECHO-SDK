# Full Ashfall Template

The official Ashfall showcase profile for ECHO Launcher exports. It integrates the 1.0.0 content wave into an Ashfall-only first-play route while keeping reusable ECHO modules standalone.

Theme: `ashfall`
Config presets: `ashfall_default`
ECHO version: `1.7.6`
Content sync label: `1.0.0 Ashfall showcase sync`

## First 10 Minutes

- Open Terminal and read the Ashfall field dashboard.
- Read the Ashfall Showcase Flow Index entry.
- Scan drop-pod wreckage with Lens and pin the first HoloMap marker.

## First 30 Minutes

- Accept the Ashfall Showcase Opening mission.
- Respond to the first WeatherCore toxic-front warning.
- Recover the first relic field note.
- Repair the pod PowerGrid spine.

## First 2 Hours

- Install the first Armory upgrade.
- Follow the first faction/story signal.
- Use Logistics, Convoy, Nexus, Orbital, Stationfall, and Blackbox hooks only when the profile route calls for them.
- Verify Ashfall-specific content remains in the official profile or `echoashfallprotocol` namespace.

- Index page: `echo_template_full_ashfall:showcase_flow`
