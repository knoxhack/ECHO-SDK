# Tech Template

A 1.0.0-synced Tech starter that keeps the existing 1.0.0 Tech wave content and makes the first generator, battery, processor, depot, and Terminal dashboard path explicit.

Theme: `tech_console`
Config presets: `tech_normal`, `low_end_performance`
ECHO version: `1.0.0`
Content sync label: `1.0.0 template sync`

Ashfall is not included in this template.

First 10 minutes:
- Open Terminal and read Power Basics.
- Build a starter generator or reinforced solar path.
- Place a Field Battery Bank and inspect stored power.

First 30 minutes:
- Route High Voltage Cable through a Factory Substation.
- Run the first Industrial Nexus processor recipe.
- Place a logistics depot beside the powered machine row.
- Open Terminal again and confirm the next-step dashboard.

First 2 hours:
- Automate the first depot request loop.
- Validate the factory power spine and note failure reasons in Index.
- Review RuntimeGuard budget guidance before duplicating machine rows.

Starter content:
- Mission: `echo_template_tech:starter_progression_sync`
- Index page: `echo_template_tech:starter_timeline`
- Tutorial card: `echo_template_tech:starter_timeline`
- HoloMap marker: `echo_template_tech:factory_commissioning_point`

Known issues:
- PowerGrid values remain stable for the existing Tech wave.
- Generated packs include starter content but still need real screenshots before storefront submission.

Do not include:
- Vanilla-only packs
- No-tech RPG packs
