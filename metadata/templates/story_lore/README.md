# Story/Lore Template

A story foundation with Terminal archive start, SignalOS chapter sample, Lens clue objective, HoloMap story marker, and mission chain guidance.

Theme: `rpg_journal`
Config presets: `cinematic`, `normal`
ECHO version: `1.0.0`
Content sync label: `1.0.0 template sync`

Ashfall is not included in this template.

First 10 minutes:
- Open Terminal and read the first archive.
- Accept the starter story mission.
- Pin the first story marker on HoloMap.

First 30 minutes:
- Scan a story clue with Lens.
- Read the Index page that summarizes the chapter.
- Complete the first mission step and unlock the next archive note.
- Review the Terminal next-step summary.

First 2 hours:
- Add two more chapter records and connect them to missions.
- Use SoundCore for subtle progression notifications.
- Build a Terminal dashboard that reflects the creator setting.

Starter content:
- Mission: `echo_template_story_lore:starter_progression_sync`
- Index page: `echo_template_story_lore:starter_timeline`
- Tutorial card: `echo_template_story_lore:starter_timeline`
- HoloMap marker: `echo_template_story_lore:first_archive_signal`

Known issues:
- Story text is sample copy and should be replaced before publication.
- SignalOS examples are generic and intentionally avoid official-pack terms.

Do not include:
- Utility-only packs
- Official-pack clones without profile separation
