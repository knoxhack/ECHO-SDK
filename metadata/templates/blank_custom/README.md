# Blank Custom Template

A guided Blank Custom starter with Core, NetCore, Index, TutorialCore, MissionCore, and HoloMap scaffolds plus one replaceable first-session loop.

Theme: `default_dark`
Config presets: `normal`
ECHO version: `1.0.0`
Content sync label: `1.0.0 template sync`

Ashfall is not included in this template.

First 10 minutes:
- Open Index and read the Blank Custom orientation page.
- Open the starter TutorialCore card.
- Track the starter HoloMap marker.

First 30 minutes:
- Complete the minimal MissionCore checklist.
- Rename the sample Index page to match the pack concept.
- Pick the first additional module or config preset.
- Run pack validation after changing the scaffold.

First 2 hours:
- Replace the sample mission with a real chapter objective.
- Add one pack-specific Index entry and one tutorial hint.
- Export and validate a client and server manifest.

Starter content:
- Mission: `echo_template_blank_custom:starter_progression_sync`
- Index page: `echo_template_blank_custom:starter_timeline`
- Tutorial card: `echo_template_blank_custom:starter_timeline`
- HoloMap marker: `echo_template_blank_custom:starter_marker`

Known issues:
- Starter content is sample scaffolding and should be renamed before publication.
- Only foundational guidance modules are selected by default.

Do not include:
- Players expecting finished gameplay
- Official-pack profiles
