# Openlands Official Template

Openlands is the concrete Official ECHO Pack #2 profile. It replaces the generic Pack #2 draft with a relaxed block-survival experience focused on building, farming, exploration, old roads, and waystone restoration.

## Source Of Truth

- Pack protocol module: `ECHO-Modules/addons/echoopenlandsprotocol`
- Canonical namespace: `echoopenlandsprotocol`
- Public name: `Openlands`
- Default mode: `openlands_standard`
- Supported runtime targets: `echo_native`, `echo_runtime_standalone`, `neoforge`

## Default Experience

Openlands Standard must stay relaxed:

- Gentle hunger.
- No stamina.
- No hydration.
- No food spoilage.
- No temperature damage.
- Recoverable death pack.
- Moderate hostiles.
- Forgiving shelter score.

Harder survival systems belong only in the optional `openlands_hardlands` overlay.

## MVP Promise

The first playable slice must let the player spawn, gather, build shelter, sleep, explore, restore the first waystone, and reveal map data.

## Legal Rule

Openlands must not use Minecraft branding, copied names, copied mob silhouettes, copied textures, copied sounds, or copied recipes as identity. NeoForge is an adapter target, not the content source.
