# Magic/Mystic Template

A relic-discovery starter with a guided scan, research page, safe artifact handling tutorial, mystic ambience, and a HoloMap relic marker.

Theme: `mystic_tech`
Config presets: `normal`
ECHO version: `1.0.0`
Content sync label: `1.0.0 template sync`

Ashfall is not included in this template.

First 10 minutes:
- Read the Relic Basics Index page.
- Scan the first relic clue with Lens.
- Open the artifact safety tutorial card.

First 30 minutes:
- Track a relic signal on HoloMap.
- Complete the relic scan starter mission.
- Write the first research note or creator replacement page.
- Use SoundCore ambience for discovery feedback.

First 2 hours:
- Add two research entries and link them to mission steps.
- Create one stable artifact handling rule.
- Replace sample relic language with pack-specific discoveries.

Starter content:
- Mission: `echo_template_magic_mystic:starter_progression_sync`
- Index page: `echo_template_magic_mystic:starter_timeline`
- Tutorial card: `echo_template_magic_mystic:starter_timeline`
- HoloMap marker: `echo_template_magic_mystic:relic_signal`

Known issues:
- Relic examples are placeholders and must be renamed for the target setting.
- Mystic ambience uses existing SoundCore placeholders until custom audio is supplied.

Do not include:
- Factory-first tech packs
- Pure vanilla starts
