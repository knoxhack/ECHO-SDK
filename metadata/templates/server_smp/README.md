# Server SMP Template

A server-focused starter with admin setup missions, PlayerCore permissions and home docs, RuntimeGuard budgets, shared HoloMap objectives, and server-balanced plus low-end configs.

Theme: `default_dark`
Config presets: `server_balanced`, `low_end_performance`
ECHO version: `1.0.0`
Content sync label: `1.0.0 template sync`

Ashfall is not included in this template.

First 10 minutes:
- Open the admin setup Index page.
- Confirm PlayerCore permissions and home rules.
- Run the first RuntimeGuard budget check.

First 30 minutes:
- Create a shared HoloMap objective marker.
- Complete the admin setup MissionCore checklist.
- Review backup and diagnostics docs.
- Choose server-balanced or low-end config guidance.

First 2 hours:
- Write staff-specific permission notes.
- Add one shared community objective mission.
- Recheck RuntimeGuard budgets after player count assumptions change.

Starter content:
- Mission: `echo_template_server_smp:starter_progression_sync`
- Index page: `echo_template_server_smp:starter_timeline`
- Tutorial card: `echo_template_server_smp:starter_timeline`
- HoloMap marker: `echo_template_server_smp:shared_spawn_objective`

Known issues:
- Permissions remain server-policy examples and must be adapted before launch.
- Low-end guidance is conservative and may be loosened after profiling.

Do not include:
- Single-player story campaigns
- Packs without admins
