# Vanilla+ Template

A lightweight ECHO-enhanced vanilla starter that now includes a guided first-session loop for homes, Index pages, map markers, and gentle optional missions without changing the core feel.

Theme: `vanilla_book`
Config presets: `easy`
ECHO version: `1.0.0`
Content sync label: `1.0.0 template sync`

Ashfall is not included in this template.

First 10 minutes:
- Open Index and read the Vanilla+ welcome page.
- Set a home or safe return point with PlayerCore.
- Create one HoloMap marker for base, farm, mine, or village.

First 30 minutes:
- Finish a small shelter or base corner.
- Mark a farm, mine, or village on the starter HoloMap layer.
- Complete the gentle MissionCore checklist.
- Review the TutorialCore card if a module is unfamiliar.

First 2 hours:
- Expand the first base and document recurring routes in Index.
- Use PlayerCore homes and HoloMap markers to connect farms, mines, and villages.
- Add creator-specific checklist objectives if this becomes a light SMP pack.

Starter content:
- Mission: `echo_template_vanilla_plus:starter_progression_sync`
- Index page: `echo_template_vanilla_plus:starter_timeline`
- Tutorial card: `echo_template_vanilla_plus:starter_timeline`
- HoloMap marker: `echo_template_vanilla_plus:vanilla_safe_base`

Known issues:
- HoloMap markers remain optional if HoloMap is not selected.
- MissionCore goals are intentionally soft and should be rewritten for heavily customized packs.

Do not include:
- Tech factories
- Horror investigations
- Official pack campaigns
