# Horror Template

A generic horror investigation starter with evidence scans, first archive guidance, danger and clue markers, SoundCore stinger rules, and investigation Index pages.

Theme: `horror_monitor`
Config presets: `cinematic`, `normal`
ECHO version: `1.0.0`
Content sync label: `1.0.0 template sync`

Ashfall is not included in this template.

First 10 minutes:
- Read the signal investigation Index page.
- Scan one evidence object with Lens.
- Enable the first investigation hint.

First 30 minutes:
- Open the first archive entry.
- Follow a HoloMap clue marker while noting nearby danger.
- Complete the starter evidence mission.
- Review SoundCore stinger and ambience notes.

First 2 hours:
- Add a second evidence type and archive page.
- Tune HoloMap marker visibility to avoid spoiling reveals.
- Replace sample tension text with pack-specific pacing.

Starter content:
- Mission: `echo_template_horror:starter_progression_sync`
- Index page: `echo_template_horror:starter_timeline`
- Tutorial card: `echo_template_horror:starter_timeline`
- HoloMap marker: `echo_template_horror:evidence_signal`

Known issues:
- Starter stingers reference existing SoundCore placeholders until custom OGG assets are added.
- Danger marker visibility should be retuned for each published investigation.

Do not include:
- Bright utility-only packs
- Factory automation starts
